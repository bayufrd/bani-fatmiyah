🔧 CUSTOMIZATION GUIDE
═══════════════════════════════════════════════════════════════════════════════

1. Menambah Anggota Keluarga
   File: src/data/familyData.ts
   Add new object to familyData array with:
   - id, name, arabicName, birth, death, gender, parentId, generation

   File: tailwind.config.ts
   Modify theme.extend.colors section

3. Mengubah Styling
   File: src/styles/globals.css
   Edit Tailwind CSS utilities & custom classes

4. Menambah Halaman Baru
   Create: src/app/[folder-name]/page.tsx
   Export default React component
